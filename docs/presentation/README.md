# Презентация темы ВКР

- `project.pptx` — актуальная редактируемая презентация.
- `project.pdf` — её версия для просмотра и пересылки.

Изменения вносятся в тот же PPTX. После правок обновляется PDF. Историю версий
хранит Git; файлы с суффиксами `v2`, `final` и другими номерами не создаются.

Титульный и заключительный слайды взяты из шаблона ИТМО, содержательные —
из его белого макета слайда 6. Язык проверки русского текста — `ru-RU`.
